# W13 - Monitoring Gerakan dan Jarak

Dashboard baca-saja (GitHub Pages) untuk sistem ESP8266 + PIR + HC-SR04 yang mengirim data ke ThingSpeak.

Website: https://mubarak-ux.github.io/w13-monitoring/

Field ThingSpeak: 1 Jarak_cm, 2 PIR_gerak, 3 Alarm, 4 Kedekatan_persen, 5 Rentang_valid.

Repositori ini hanya berisi HTML dan Channel ID publik. Tidak ada SSID, password Wi-Fi, atau Write API Key.
